Import

Start from the current rosters: download them, edit the file in Excel or any text editor, and load it back. One row per player, 8–12 players a team; slots 1–5 are the starters. The team_id column picks which of the VBL franchises the row belongs to; city, nickname, abbreviation and colours can all be changed in the same file. Ratings run 35–99, height is in inches (cm also accepted). Traits: * star, + sparkplug, ! enforcer, D dunker. Teams you leave out keep their current roster.
The commentator only says a city out loud if it is the franchise's original city or a city that has had an NBA team between 1993 and 2026. Any other city is never named on air: the team is just “the home team” or “the visitors”.
