Changes are saved in this browser as you go, and Vintage Puck uses them on its next start when it runs from the same place (the same folder on this computer, or the same itch.io page).
To take the uniforms elsewhere, download vpuck-kits.js and put it in the game folder next to index.html (for itch.io, add it to the zip). Colours saved in a browser take priority over the file.
