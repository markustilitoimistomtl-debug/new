# Headway – Godot port: guide for Claude Code

The owner speaks Finnish: talk to them in Finnish. All in-game text (UI, messages, settings) is **English**.

## What this is

Headway is an adventure game (inspired by *Lost*): a party is stranded at a base camp on a remote island,
~200 km from the nearest coast. The playable prototype exists as a single-file browser game
(`../peli.html`, same as `../headway.html`). This folder is its **Godot 4.3 port** and is the version that
goes forward (Windows .exe). The browser game is the **functional specification**: port behaviour from it,
then improve visuals with what Godot allows.

Story, characters' ailments, buildings, people and vehicles are **not** designed yet – do not invent story content.

## Run and verify

- Godot 4.3 (standard, not .NET) is installed on the owner's machine. Find the executable (ask the owner if
  `godot` is not on PATH). Run: `godot --path headway-godot` or open `project.godot` and press F5.
- Screenshot mode for checking your own work (renders, saves a PNG, quits):
  `godot --path headway-godot -- --shot=out.png --frames=30 --cam=X,Z,DIST,PITCH,YAW`
  (camera target in map metres, pitch in radians, e.g. `--cam=-2240,-1200,140,0.9,0.6` = the airstrip).
  Look at the screenshot before telling the owner something works.
- After adding textures/audio run `godot --headless --path headway-godot --import` once.
- Windows build: Project → Export → Windows Desktop (preset exists, output `build/Headway.exe`;
  the editor downloads export templates on first use).

## Layout

| Path | Purpose |
|---|---|
| `scripts/main.gd` | builds the scene: environment, terrain, water, forest, aircraft, party, camera, input, HUD, screenshot mode |
| `scripts/map_data.gd` | loads `maps/<name>/` (map.json, heights.f32, water.f32, land.u8); height/water/land queries in map-local metres |
| `scripts/terrain.gd` | terrain mesh and flat water surfaces |
| `scripts/forest.gd` | tree species meshes from textured foliage cards + placement (tiles of 384 m, visibility range 620 m) |
| `scripts/character.gd`, `aircraft.gd`, `box_model.gd`, `rts_camera.gd` | party member, parked aircraft, box mesh helper, AoE camera |
| `shaders/*.gdshader` | terrain (land-cover + painted airstrip), water, foliage (alpha scissor, wind, soft crown normals), bark |
| `textures/*.png` | foliage cards, generated by `tools/make_foliage_textures.py` (Python + Pillow) |
| `audio/engine.mp3`, `audio/theme.mp3` | aircraft engine loop (already 4× volume) and theme music (already trimmed) |
| `maps/north_coast_42/` | the camp map, already processed (levelled water bodies, graded airstrip, camp position) |

Map coordinates: map-local metres, origin at the map centre, x east, z south, cell `i = z*n + x`,
cell centre `x = (cx - (n-1)/2) * cellSize`. Heights are metres; render height = metres × `exaggeration` (1.6).
`water.f32` is NaN where there is no water surface. Land-cover ids 0–19 (0 forest, 8 lake, 9 sea, 13 wilderness,
14 meadow, 15 clear-cut, 16 wetland, 17 rock, 18 beach …, see `map.json` palette).

## Decisions already made with the owner (keep them)

- Game name **Headway**. Characters: **Leilani** (orange shirt), **Mateo** (blue, the only pilot), **Nia** (green). No ailments yet.
- Views: **Local** = AoE-style close view with detailed trees and the characters; **Aerial** = overview/flyover.
  Detailed trees only in Local; Aerial keeps the simpler level of detail.
- The camp has no roads; it is on an island ~200 km offshore. Nothing is reachable on foot beyond "uncleared areas".
- Bottom toolbar, centred at the bottom edge, buttons joined together, compact, no background panel:
  compass (mini map on/off) · Local · Aerial · Tools (opens a tool tray) · gear (settings) · active character's portrait.
  Mini map in the bottom-left corner, flush to the edges; its top-right arrow opens the full-screen map and turns into a
  small plane icon when a pilot is aboard the aircraft. Portrait: first press centres the character, second press
  switches to the next one. **Tab** also switches.
- Energy ball above the active character: green → red with energy; shows a number when the character has a condition
  (days it can wait for care, 0 = life-threatening). Hovering a character shows energy, water, food and condition.
- 2D map is cartographic (flat muted colours like a road map, not shaded terrain). Uncleared areas are **black**;
  mapped areas have rounded, irregular, feathered edges. Place names only on the full map. Walking on the ground maps
  ~350 m around the route; flying maps nothing. Only cleared areas have airfields.
- Flights: Aerial alone flies nobody. A pilot must walk to the aircraft (click it) and board; then the plane icon
  opens the map where only airfields can be picked; speed slider on the map; letterboxed takeoff/landing
  cinematics; occupants disembark on landing, others stay where they were.
- Story destinations appear on the map as 14 km mapped circles with a generated airstrip
  (`STORY.addDestination({name,x,z})` in the browser game). A test city **Port Meridian** exists.
- Uncleared areas: walking off a map continues the local view on terrain generated from the world (forest, fields,
  shore, hidden motorways/railways – no houses or vehicles). Energy, water and food drain there and refill at camp;
  running out sends the character back. Hitchhiking needs money and only works on story routes.
- Theme music plays in intro/main menu (not built yet) and while settings or the full map are open, fading out when
  closed and resuming where it stopped, looping. Engine sound during takeoff, flight and landing.
- No sound effects beyond these for now.

## Roadmap (do in this order, show the owner screenshots after each step)

1. **Local view UI**: bottom toolbar, mini map + full map (camp map only), portrait, Tab, energy ball, hover card,
   resources (energy/water/food/money), settings panel (sun, sound volumes, tree density). Ref: `syncBar`, `syncBall`,
   `showCard`, `resTick`, `drawMap`, `campOutline` in `../peli.html`.
2. **Sound**: engine + theme rules above. Ref: `soundTick`.
3. **Aircraft**: boarding/pilot rules, takeoff and landing cinematics with the aircraft rolling on the strip.
   Ref: `board(`, `takeoff`, `landing`, `takeoffPose`/`landingPose`.
4. **Aerial / world**: procedural continent 4096 × 3072 km (port `worldH`, `climate`, `chooseSiteSpot`, `prepareSite`
   so the island and map edges match), flown at ~1 km with LOD terrain chunks; world map with airfields;
   autopilot flight at the chosen speed. Ref: `worldH`, `climate`, `cdSelect`, `airTick`, `goAerial`.
5. **World content**: Port Meridian (`buildCity`), destinations (`STORY.addDestination`, `chooseRunwayW`, `landAway`,
   `takeoffAway`), hidden transport network (`buildNetwork`), uncleared-area terrain (`buildWild`), mapping (`reveal`).
6. **Map import**: load any Terrain Forge `project.json` directly (port `processWater`, `chooseRunway` + grading, camp choice)
   instead of the pre-processed files.
